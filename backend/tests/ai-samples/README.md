# Регрессионный набор: фото настоящих паспортов

Здесь лежат фото страниц паспортов, по которым проверяется AI-скан (спецификация, раздел 5.5).
**В git попадает только этот файл**: на фото есть личные данные (имя и адрес владельца).

## Как добавить образец

1. Создай здесь папку с понятным именем, например `murka-rabies`. Одна папка — один скан.
2. Положи в неё фото страниц: jpg, png или webp. Страницы идут по порядку имён: `1.jpg`, `2.jpg`…
3. Запусти из папки `backend`:

   ```sh
   COLLARBELL_REAL_AI=1 dotnet test -- --filter-method "*Real_passport_photos_read_as_expected"
   ```

4. Рядом с фото появится `draft.json` — то, что прочитала модель. Сверь его с бумагой, исправь ошибки
   и сохрани как `expected.json`. Поля, которые проверять не нужно, можно удалить.
5. Дальше каждый запуск сравнивает новое чтение с `expected.json`. Итог — в `report.md` в этой папке.

Сравнивается: вид записи и дата (по ним записи находят друг друга), препарат, серия, «действует с/до»,
болезни прививки, номер чипа, номер паспорта, страна, дата выдачи. Лишние записи тоже считаются ошибкой.

## Фото для скана номера чипа

Скан номера чипа в форме питомца («С фото») проверяется отдельно, по папке `chips`. В ней лежат фото наклеек
с чипом и страниц паспорта с номером, по одному фото на скан. **Имя фото — номер чипа на нём:**
`chips/643094100000001.jpg`. Скан паспортов эту папку пропускает.

```sh
COLLARBELL_REAL_AI=1 dotnet test -- --filter-method "*Chip_photos_give_the_number_they_are_named_after"
```

Тест проверяет, что модель прочитала номер из имени фото. Всё прочитанное (тип, место, дата) он кладёт рядом
с фото: `643094100000001.json`. Место и дату сверь с бумагой глазами.

## Сколько стоит фото

Каждый ответ модели тест дописывает в `spend.md` в этой папке: тест, модель, сколько токенов ушло на вход и на ответ,
сколько из ответа заняли «размышления» модели и цена по платному gemini-3.8-flash с 2027 года ($1,50 за 1 млн токенов
на вход, $7,50 — на ответ вместе с размышлениями). Итог по сканам — в конце `report.md` и `chips/report.md`.

Чтобы сравнить, сколько модели думать, запусти с `COLLARBELL_AI_THINKING=Low` (или `Medium`, `High`). Это то же, что
настройка `Ai:Thinking` на сервере:

```sh
COLLARBELL_REAL_AI=1 COLLARBELL_AI_THINKING=Low dotnet test -- --filter-trait "Category=RealAi"
```

## Когда запускать

После смены промпта (`PassportScanPrompt.Version`, `IdentifierScanPrompt.Version`) или моделей (`Ai`
в `appsettings.json`). Цель по спецификации: 20 фото сейчас, 50–100 документов к запуску.
