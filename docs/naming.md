# Название продукта: проверка свободных имён

> 2026-10-01. **Выбрано: Collarbell.** Рабочее имя «Pawkeep» оказалось занято. Ниже - как проверяли кандидатов и что нашли.

## Как проверяли

Для каждого кандидата:

| Источник | Как |
|---|---|
| App Store | iTunes Search API, страны US, GB (для финалистов ещё DE, FR, ES, IT, CA, AU); написание слитно и раздельно |
| Google Play | Страница поиска, US, слитно и раздельно |
| Домены .com, .app, .pet | RDAP реестров (Verisign, Google Registry, Identity Digital); для финалистов .com дополнительно whois («No match» = свободен) |
| Товарные знаки США | API поиска USPTO: точное совпадение, раздельное написание, нечёткий поиск (до 2 правок), слова в любом порядке |
| Компании Великобритании | Поиск Companies House |

**Методика откалибрована на Pawkeep:**
- в App Store три приложения «PawKeep» / «Pawkeep» 2026 года и несколько «PawKeeper»;
- `pawkeep.com` зарегистрирован с 22.05.2024;
- `pawkeep.app` занят.

**Не проверено (сделать вручную до регистрации):**
- товарные знаки ЕС и международные: [EUIPO eSearch](https://euipo.europa.eu/eSearch/), [TMview](https://www.tmdn.org/tmview/), [WIPO Global Brand Database](https://branddb.wipo.int/) - TMview из этой сети не отвечал;
- общий поиск по вебу и соцсетям: в сессии закончился лимит веб-поиска.

- **Collarbell** - колокольчик на ошейнике.
